# Prism

Liquid glass. Frosted glass panes over an aurora night: translucent panels, light that follows the pointer and stained-glass accents.

Select the theme through Administration > Themes. Colours and corner radius can be changed under Theme colours; the defaults are defined in theme.json. Content, server addresses and uploaded images come from the site owner. The included original artwork can be replaced with the site owner's own home image.
