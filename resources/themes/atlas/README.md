# Atlas

Network command. An original VibeCraft theme with its own home composition, navigation treatment, typography and store layout. Shared views preserve authentication, purchase and support behavior.

Select the active layout through Administration > Themes. Validated colour and radius defaults are defined in theme.json; a browser palette editor is not implemented in this development version. Content, server addresses and uploaded images come from the site owner. The included original world artwork can be replaced with appropriately licensed operator artwork.
